Jennie Zhan Writing Sample

Financial Market Event Analysis

This project investigates how major financial sectors responded to the escalation of the Russia–Ukraine War in February 2022. Using event study methodology and difference-in-differences analysis, the report examines abnormal returns across energy, defense, technology, airline, and European equity funds.

Machine Learning Portfolio Optimization

This project combines machine learning and portfolio optimization to explore whether predictive models can improve investment decision-making. Random Forest, XGBoost, and LSTM models were evaluated for return prediction, and the resulting forecasts were incorporated into a Mean Absolute Deviation portfolio optimization framework.

Jiawen Tang Writing Sample

AI-Assisted Medical Image Classification

This report explores the use of artificial intelligence to support insurance claim review workflows involving medical imaging evidence. Using brain MRI data, the project compares a baseline Convolutional Neural Network (CNN) with an EfficientNetB0 transfer learning model to classify multiple tumor categories. The analysis evaluates model performance, discusses operational applications in insurance review processes, and highlights the importance of human oversight and responsible AI deployment in healthcare settings.
